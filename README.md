# LevelPrint CRM

Материалы, проекты и калькуляция проектов (маржа ×3 + НДС 12%). Интерфейс на русском и узбекском.

## Запуск

Нужен Node.js версии 22.5 или новее (https://nodejs.org). Других установок не нужно.

- Windows: дважды щёлкните `start.bat`, или в этой папке выполните `npm.cmd start`.
- Откройте в браузере http://localhost:3000

При первом запуске сайт попросит создать администратора. Остальных сотрудников
администратор добавляет в разделе «Админ-панель». Регистрации нет.

## Права

| | Администратор | Сотрудник |
|---|---|---|
| Создавать и редактировать проекты | да | да |
| Удалять проекты | да | нет |
| Смотреть материалы | да | да |
| Добавлять и менять материалы | да | нет |
| Админ-панель (сотрудники, маржа, НДС) | да | нет |

## Расчёт

- Сумма строки = количество × цена
- Маржа = сумма × 3 (коэффициент меняется в админ-панели)
- НДС = сумма с маржой × 12%
- Итого = сумма с маржой + НДС

## Данные

Вся база хранится в одном файле `data/levelprint.db`. Чтобы сделать резервную копию,
скопируйте этот файл (лучше при остановленном сервере).

## Импорт материалов

Материалы из Excel-базы (11.09.2025) лежат в `import/materials-2025-09-11.json`.
Импорт в базу (повторный запуск безопасен — дублей не будет):

    node scripts/import-materials.js import/materials-2025-09-11.json

Если материал с таким названием уже есть, остаётся более высокая цена.
Копия базы перед первым импортом: `data/backup/levelprint-before-import-2026-11-25.db`.

## Сотрудники

Должность (Директор, Финансовый директор, Снабженец, Печатник, Менеджер по продажам, Работник)
и доступ (Администратор / Сотрудник) задаются отдельно. При выборе директора или финансового
директора доступ «Администратор» подставляется автоматически, его можно поменять.

## Тема

Кнопка с луной/солнцем внизу меню переключает светлую и тёмную тему. Печать всегда светлая.

## Прайс-лист

Раздел «Прайс-лист» — готовые цены для клиента (перенесены с бумажного прайса, `import/pricelist.json`).
В калькуляции позиции из прайс-листа добавляются через «Из прайс-листа»: маржа ×3 к ним **не** применяется,
НДС добавляется. Позиции без цены («по запросу») добавляются с ценой 0 — цену нужно вписать в строке.

    node scripts/import-pricelist.js import/pricelist.json

## Поиск и категории

Поиск понимает кириллицу и латиницу и прощает ошибки в гласных: «аракал» найдёт Orakal, «фомекс» — Fomiks.
На странице «Материалы» есть фильтр по категориям и сортировка (по категориям, по названию, по цене).
